# Lycian Way Trail, Segment, Point and Cultural Storytelling Dataset (v2.0.0)

Dataset 1 of the **TRAIL – Lycian Odyssey** Digital Rural–Urban Enabler, developed by ATAM Technology, Artemis Outdoor and Antalya SKAL within the RURBANIVE Open Call (Horizon Europe, project 101136597). The companion audio recordings are published as *Lycian Odyssey Audio Dataset* (Dataset 2).

Release date: 7 November 2026. This release replaces v1.0.0 (24 February 2026) and reflects the consolidated catalogue published in the TRAIL application. All published trails have been walked and checked in the field by Artemis Outdoor.

## Contents

| File | Content | Records |
|---|---|---|
| `trails.geojson` | Published Lycian Way stages as LineString features | 41 |
| `trails.csv` | The same trails in tabular form with start and end coordinates | 41 |
| `segments.csv` | Original Lycian Way segments referenced by the points of interest | 44 |
| `points_of_interest.geojson` | Published points of interest as Point features | 399 |
| `points_of_interest.csv` | The same points of interest in tabular form | 399 |
| `stories.csv` | Full texts of the location-linked cultural stories | 37 |
| `data_dictionary.csv` | Description of every field | – |

Coordinates use WGS 84 (EPSG:4326). Texts are in English. Encoding UTF-8.

## Coverage

Lycian Way corridor in the provinces of Antalya (NUTS3 TR611) and Muğla (NUTS3 TR323), Türkiye.
